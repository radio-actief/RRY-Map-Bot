# :radioactief: Radio-Actieve Bot
## :meshcore: :flag_be: MeshCore Node Beheer
Welkom bij de **Radio-Actieve Bot** instructies!
Deze gids behandelt specifiek het **MeshCore** gedeelte van de bot.

De bot helpt je met het beheren van je MeshCore netwerk nodes en moedigt contact aan met andere gebruikers in de Belgische community.

Deze synchroniseert meermaals per dag van de officiële MeshCore map en voegt samen met Discord-geregistreerde nodes op de [🇧🇪 **BE Map**](https://map.axistem.eu).

Als je node op de officiële map staat, kunnen Discord-aanpassingen worden overschreven. We zoeken een balans voor de meest accurate info. Vragen? Zie "**_:sos: Hulp_**" onderaan.

### :rocket: Aan de slag
Is jouw node al opgeladen op de officiële map? Dan kan je deze hier aan jouw Discord account koppelen met **`/node claim`**.

Of wil je eerder jouw node enkel op de Belgische map, gebruik dan **`/node register`**.

### :clipboard: Je Nodes Beheren
- **`/mynodes`** - Bekijk al je nodes
- **`/node claim`** - Claim een onbeheerde node
- **`/node update`** - Update naam, stad, frequentie of coördinaten
- **`/node unclaim`** - Geef je node vrij
- **`/node register`** - Registreer een nieuwe node (enkel op de Belgische map)
- **`/node delete`** - Verwijder een Discord-geregistreerde node die je bezit

### :mag: Zoeken
- **`/search`** - Zoek op query _(naam of plublic key)_, type, stad, frequentie, eigenaar, ...
_Voorbeelden_: `/search query:ABC123` of `/search query:USER_R1 node_type:Repeater city:Brussel`

### :bar_chart: Statistieken
- **`/stats`** - Algemene netwerk statistieken (nodes, types, presets, steden, activiteit)
- **`/stats-cities`** - Lijst alle steden met node aantallen
- **`/stats-frequencies`** - Frequentie stats per node type
- **`/stats-source`** - Node aantallen per bron type
- **`/recent`** - Recent bijgewerkte nodes (laatste 24 uur)

### :bulb: Tips
- **Slim zoeken**: Het `query` veld accepteert volledige/gedeeltelijke public keys of node namen
- **Node types**: 📱 Companion | 📡 Repeater | 💾 Room Server | 🌡️ Sensor
- **Zichtbaarheid**: Zoekresultaten/stats zijn publiek; je node lijst, fouten en coördinaten zijn privé.
